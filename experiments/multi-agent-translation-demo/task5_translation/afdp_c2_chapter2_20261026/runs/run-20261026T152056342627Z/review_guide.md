## Glossary
- [ ] 候选特征是否足以支持收录？
- [ ] Agent 是否排除了普通词和候选噪声？
- [ ] 译法是否符合本章语境？
- [ ] 是否遗漏低频但关键的概念或缩写？

## Translation
- [ ] 是否漏译、增译或改变原文含义？
- [ ] 数字、否定和条件是否保留？
- [ ] 术语是否统一，中文是否自然？

## Proofreading
- [ ] 指出的问题能否在译文中定位？
- [ ] 问题是否真实，建议是否可执行？
- [ ] 是否漏掉了人工发现的问题？本角色未读取原文。

## Manager
- [ ] 修订对象是否对应审校意见？
- [ ] 修订理由是否有报告依据？
- [ ] 是否忽略问题或要求无依据的重译？

修订稿需要另行对照原文复核；原版审校角色检查的是初稿译文，不是原文忠实性或修订后的验收。
