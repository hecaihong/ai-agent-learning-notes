## 准备

准备阶段代表了规划与执行之间相互重叠的活动，用于共享信息、达成共识、说明任务并优化作战行动。有效的准备包括通过推演或演习确保过渡活动被充分理解，通过检查和核验确认战备状态，以及在执行前及时进行反向简报以汲取经验教训。

准备涵盖了必要的协调、细化和过渡行动，以确保上级、下级和平行部队之间实现顺畅沟通和成功执行。准备通过建立共同作战图景，确保从规划到执行的无缝过渡。这使得规划人员能够顺利将工作移交给执行人员，确保所有利益相关方保持一致并了解各自的角色和职责。成功过渡的关键指标包括：

- 所需资源和支援的可用性。
- 对任务、职责和时间线的清晰理解。
- 不同单位和机构之间的有效沟通与协调。
- 规划人员与执行人员之间及时准确的信息交换。

**协调。** 协调被定义为确保充分信息交流的必要行动，以整合、同步和消除独立组织之间作战行动的冲突。它涉及共享信息以达成共识、说明任务并优化作战行动。执行前的协调对于确保所需支援到位至关重要。指挥官应当共享信息（纵向和横向），以建立信任关系，并达成高效多国和联合行动所需的协议。协调的益处包括通过消除冲突将误伤风险降至最低，以及增进对作战环境的整体理解。协调不替代正式审批流程，通常用于支援参谋各职能之间。

直接联络授权（DIRLAUTH）用于与直接参谋或组织之外的组织进行协调，或用于各军种参谋之间的协调。尽管联合部队的每个组成部分都作为联合部队指挥官整体工作的一部分制定各自的计划，但如果这些计划在各军种组成部分之间进行了协调，则最为成功。计划应在执行前尽可能留出充足时间进行协调，以确保为作战行动协调好所有所需支援。

**准备作为独立步骤**

以往对主要指挥与控制活动的分类将准备视为规划末尾或执行开始的子活动。大量经验教训表明，缺乏独立的准备活动导致规划和执行过程中对执行作战行动所需时间和资源要求的忽视。

协调行动的示例包括：与联合部队各组成部分共享情报、监视与侦察（ISR）资产；与加油机和空运单位协调燃油和运输支援；以及与相邻单位同步空域管理。

**细化。** 细化是指因执行前出现的变更而对计划中的作战概念进行修改。这确保计划在应对不断变化的情况时保持相关性和有效性。

细化行动的示例包括：根据变化的太空或地面天气条件调整空中任务指令（ATO），根据新情报细化目标清单，以及更新空域控制计划（ACP）以容纳额外飞机。

**过渡。** 过渡是一个包含执行前最终活动的过程。指挥官举行推演和演习以确保参谋人员准备好进入执行阶段。生成检查清单并建立战斗节奏以支持指挥官的决策周期。检查核验下级单位的战备状态，确保他们理解自己的任务。最后，在远程规划人员正式将计划移交给作战执行人员时，传达经验教训。过渡通常以下达将计划付诸行动的命令而结束。

## 执行

执行是在将计划付诸行动的同时，运用态势理解评估进展并根据情况变化调整作战行动。执行中的指挥与控制侧重于夺取和保持主动权、建立和维持势头以及利用成功的活动与决策。通过执行中的指挥与控制，指挥官可以根据需要监视和调整作战行动。因此，执行中的指挥与控制直接与指挥官的决策周期相关联，因为指挥官、参谋人员和下级指挥官将精力集中于将决策转化为行动。他们指挥行动，在决定性地点和时间运用战斗力以实现目标和完成任务。此外，执行还包括根据下级单位实施的变更来整合和同步作战行动。

**生成。** 第一个执行活动通常是生成。生成包括使部队进入与计划一致且能够执行指挥官意图的态势。生成空中力量所需的行动涉及从任务生成到全球力量管理（例如全球力量部署、分阶段部队与部署数据[TPFDD]管理、建立警戒状态、转运）等一系列组织和流程。生成行动的示例包括为作战行动部署中队、生成架次以及为防空系统分配任务。

执行标志着指挥官角色的根本性转变。指挥官在规划和准备阶段深度参与，而在执行阶段其角色转变为授权下级代表其做出决策。执行中指挥与控制的这一根本性转变是在任务式指挥理念下实现分散执行的关键。

执行在指挥官指示下开始。指挥官可以使用多种方法下达执行命令。一般而言，空中组成部分指挥官和下级梯队可能使用任务式指挥技术来清晰传达指挥官意图，并授权空军人员在复杂、快速展开的作战行动中做出有效的现场决策。

分散执行是任务式指挥理念指导下作战行动的基本特征。分散执行的必要性源于这样一个前提：关于战术运用的决策由最接近战斗的人员做出时最为优化。具备战术素养的空军人员，在清晰的指挥官意图以及对作战行动目的和更广泛作战与战略背景的共同理解武装下，能够最大限度地发挥空中力量的杀伤力。历史表明，分散执行所产生的行动速度是在敌方决策周期内行动的最可靠方法。分散执行提升战术层面的有效性和韧性。

**战斗管理。** 执行中的指挥与控制就是战斗管理——即根据相应权威下达的命令、指示和指导，对作战环境内的活动进行管理。这些活动包括在指挥官确定的可接受风险水平内指挥武器、传感器和支援的过程，以实现指挥官意图。战斗管理允许根据指挥官意图和指挥官命令范围对作战行动进行直接且通常是实时的监视。有效战斗管理的成果包括及时决策、传达评估结果和解决问题。战斗管理通过指挥与控制节点实现分散作战。

**指挥与控制节点。** 指挥与控制节点是指挥与控制系统中代表执行分散作战的人员、场所或物理对象的要素。指挥与控制节点的常见示例包括战区空中控制系统（TACS）中的要素，如任务指挥官（MC）、机载预警与控制系统（AWACS）、前进空中控制员（FAC）和战斗控制中心（BCC）。节点可能跨越多个作战层级并具有不同级别的能力。指挥与控制节点应当了解其权限、在决策和执行中的角色以及与其他节点的关系。

**战术指挥与控制。** 某些指挥与控制节点被称为战术指挥与控制（TAC C2）。战术指挥与控制是在战术层面进行战斗管理的要素，即使这些战术行动具有战区范围的影响。通常，战术指挥与控制管理特定任务。任务是基本任务及其目的，明确指示应采取的行动及行动原因。任务通常与空中组成部分相关，其形式为派遣飞机完成任务。任务执行始于任务发射决策，包括确保有效完成的所有必要职能。

> **战斗管理示例：全球空中机动调整**
>
> 战斗管理使用多种指挥与控制系统。对于空中机动行动，全球空中机动支援系统（GAMSS）是支持空中机动行动的指挥与控制系统。在执行期间，GAMSS指挥与控制节点执行战斗管理以应对作战环境中的动态变化。
>
> 例如，2010年4月16日，冰岛埃亚菲亚德拉冰盖火山爆发，喷出的火山灰云关闭了欧洲大部分空域。作为回应，由第618空中作战中心进行战斗管理的近400架次空运、加油和航空医疗后送任务被改道，以确保继续向阿富汗和伊拉克投送人员与装备以支援增兵行动。最终，执行中的有效指挥与控制改道了600多架次任务，运送了超过17，000吨物资，运送了超过47，000人员，克服了计划外的危险。
