## 评估

评估始于对战术任务和目标的界定。评估是一项持续性活动，参谋人员通过它观察作战环境以及朝向最终状态的渐进进展。评估驱动计划和战略的调整。作战评估帮助指挥官和参谋人员判断任务完成进度。评估结果增强指挥官的决策能力，指导更有效的作战行动，并应对不断演变的作战环境。次要目的是与上级司令部（HHQ）的优先事项、机动方案和作战目标保持一致。

将评估融入计划、准备和执行过程，可帮助各级指挥官和参谋人员：

- 制定任务成功标准，以涵盖指定任务和基本任务。
- 将观察到的作战环境条件与预期目标和/或最终状态条件进行比较。
- 确定关键计划事实和假设的有效性。
- 在执行过程中，判断是否已产生预期效果，以及目标是否正在实现。
- 在执行过程中，对照目标、任务、效果和任务遂行情况，评估所分配资源的有效性。
- 确定是否需要增加、减少或变更资源。
- 识别任务完成的风险和障碍。
- 识别加速任务完成的机会。

**基本原则。** 评估活动由以下基本原则构成：

- 确定信息和情报需求。在计划过程中，获取基线理解有助于设定目标并确定成功与失败的阈值。
- 制定或修改评估计划。将信息和情报需求与适当的度量指标和指标相关联，并包含一个收集计划以收集适当数据。
- 收集信息和情报。在执行过程中，部队使用收集计划和规定的报告程序来收集有关环境和正在进行的作战行动的信息。
- 开展定期或基于事件的评估。指挥官及其参谋人员通常根据事件或在作战行动期间的指定间隔开展评估。
- 开展变化报告。指挥官尤其关注了解友方或敌方行为与先前作战行动中建立的预期或规范相比发生了何种变化。虽然许多初始报告可能被证明是虚假的或被视为异常值，但一旦评估可靠地感知或辨别出变化模式，就应将其突出显示以引起指挥官的注意。
- 提供反馈。评估报告向指挥官和其他利益相关者通报当前状况，并传达朝向预期目标和最终状态的进展。

**评估考虑因素。** 评估是一个持续过程，衡量军事行动中运用能力的总体有效性。它也是确定完成任务、创造条件或实现目标的进展。评估通过提供对战略及配套计划有效性的洞察，支持指挥官的决策过程。评估存在多种类型，可用于支持作战行动。然而，本文件中的评估指的是支持指挥官决策过程的活动。

在基于效果的方法中，评估应为指挥官提供以下基本问题的答案：

- 我们是否在正确地做事（性能度量）？
- 我们是否在做正确的事情（效能度量）？
- 我们是否在衡量正确的事情？

第一个问题通过评估任务完成情况来解决计划空中作战行动的性能问题。第二个问题解决指挥官预期效果在作战环境中被观察到的程度，并促使审查性能与效果之间的联系。最后，第三个问题涉及评估过程以及理解如何选择衡量性能、原因和效果之间联系的重要性。当适当确定时，这些问题的答案应为指挥官提供有效信息，作为调整战略决策的依据。

虽然为了概念清晰，评估常被描述为空中任务周期的一个独立阶段，但它贯穿于作战设计、计划和执行的全过程。评估过程应在总体战略制定时开始（包括制定评估标准）。它持续贯穿于详细计划（制定度量指标和数据来源）。最后，它延伸到执行期间和执行后对度量指标的评价。这一过程是迭代的，因为评估结果会影响未来的战略和计划。

评估整合来自许多来源的数据，并应简明且结合上下文地总结这些数据。它应遵循严格、可辩护的分析过程，使指挥官和计划人员能够查看所使用方法的细节和产生的结果。它传达数据中的相关不确定性及伴随的风险。简而言之，评估应允许在分析支持下对指挥官的战略做出判断。
