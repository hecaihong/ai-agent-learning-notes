## 应用指挥与控制流程

将一项作战任务分配给下级指挥官并建立适当的部队结构，是在指挥与控制—分布式控制—分散执行（CC-DC-DE）框架内实施指挥与控制流程的前提条件。以下章节提供了应用指挥与控制流程以实现分布式控制的考虑因素。

### 分配作战任务与权限

为实施分布式控制，空中力量指挥官需清晰界定并将一项作战任务连同实施相应指挥与控制流程的权限分配给下级指挥官。在此背景下，空中力量指挥官可施加某些限制，以划定授予下级指挥官的权限范围。由于指挥与控制流程是针对特定作战任务实施的，可能存在这样的情况：下级单位对某些作战任务拥有分布式控制权，而空中力量指挥官保留对其他任务的控制权。第21页的案例提供了将控制权分配给下级梯队并赋予特定作战任务及相关作战区域的示例。在该案例中，第7440复合联队（CW）指挥官受命在海湾战争中开辟第二战线并完成若干明确界定的任务。向第7440复合联队传达指挥官意图和权限的机制是一道命令。

命令是一种通信方式——书面的、口头的或通过信号传递的——将上级的指示传达给下级。授予实施指挥与控制流程权限的命令应侧重于作战任务的目的，而非如何执行所分配任务的细节。此外，命令应明确所授予的权限是持久的、临时的还是基于条件的。⁹

### 部队结构

在作战中实现指挥与控制—分布式控制—分散执行并无强制性的结构。然而，美国空军已有既定组织可通过指挥与控制—分布式控制—分散执行框架促进指挥与控制。最相关的美国空军结构是空中远征特遣部队（AETF）。空中远征特遣部队一经组建，可充当军种组成司令部或下属军种司令部的角色，通常位于作战司令部（CCMD）层级以下。空中远征特遣部队是可扩展、可定制的组织，包含三个要素：单一且明确指定的指挥官、适当的指挥与控制机制，以及经过定制并得到充分支援的部队。空中远征特遣部队为联合部队指挥官（JFC）提供一个按任务编组且整合的套件，在部队维持、指挥与控制以及部队防护之间实现适当平衡。¹⁰

空中力量指挥官可向空中远征特遣部队指挥官授予特定的作战权限（源自其指定的指挥关系），这些权限足以对其分配或配属的部队实施指挥与控制流程。该模式支持指挥与控制—分布式控制—分散执行框架内的作战，因为战区空中力量指挥官通过其指定的指挥关系（由作战司令部司令建立的作战控制权）保持集中指挥，而空中远征特遣部队作为战区下属梯队以分布式控制方式运作。随后，战术梯队指挥官被授予执行权限以实现分散执行。

分布式控制可在多个战区下属或“中间”梯队中复制。在正常作战期间，空中远征特遣部队指挥官在对其所分配作战任务实施指挥与控制流程时，持续与战区空中力量指挥官沟通、协调并同步其作战行动，并与其他空中远征特遣部队进行横向协调。战区空中力量指挥官能够根据需要重新排定优先级并调整空中远征特遣部队的指挥与控制活动，以满足作战司令部的总体任务要求。

在争夺激烈、降级或作战受限的环境中，空中远征特遣部队拥有必要的权限，在与战区空中力量指挥官断连时对其部队实施指挥与控制。通过在降级环境出现之前授予足够的作战权限并加以行使，空中力量可继续实施有效的空中作战。参见以下“分布式控制示例”了解空中远征特遣部队如何在战区空中力量层级以下的梯队实施指挥与控制流程。

### 联合特遣部队“证明力量”：
分布式控制的历史范例

空中力量指挥官可选择通过空中特遣部队（ATF）或作战联队来实施分布式控制。随着行动单位通过赋予权力的指挥官、作战中心和强大的参谋队伍提升其指挥与控制能力，它们可能获得对其所分配部队实施指挥与控制流程的能力。以下来自联合特遣部队“证明力量”的示例突出了作战联队或空中特遣部队如何在分布式控制下运作。

在1990—1991年海湾战争期间，第7440复合联队（临时）（CW）作为联合特遣部队“证明力量”的作战力量，其人员编制旨在支援作战行动，由能够执行打击、压制敌方防空、电子战、监视与侦察、防空作战、加油和救援任务的机型组成。凭借必要的建制能力，该联队能够在没有美国中央空军（CENTAF）协助的情况下自主发射打击编队。

中央空军向该联队下达了一道命令，要求其在可能时开辟伊拉克第二战线。该命令包含三项广泛任务：1）通过攻击伊拉克北部空军基地，剥夺伊拉克空军的庇护所；2）牵制土耳其边境附近的伊拉克地面部队；3）攻击伊拉克北部的核、生物和化学设施。由于该联队部分飞机的航程不足以攻击巴格达以南地区，该联队被分配了伊拉克北部一大片责任区域。然而，中央空军保留了对该联队作战计划的指挥权限以及例外式任务分配权限。

联队指挥官唐纳准将按照指挥官意图行事，但完成三项广泛任务的方法则由其自行决定。该联队向其各中队下达命令，并允许任务指挥官构建打击编队。第7440联队自行制定空中任务指令（ATO），在唐纳将军的酌情决定下每天以两到三个波次出动50至60架次作战飞行。中央空军偶尔以例外方式对该联队进行任务分配，除此之外，霍纳将军授权唐纳将军有效地以他的联队进行“作战”。最终，第7440复合联队拥有实施整个指挥与控制流程的权限、能力和容量。唐纳将军和第7440复合联队在中央空军指挥官授予的分布式权限下规划、准备、执行和评估作战行动。

联合特遣部队“证明力量”是通过任务指挥理念和框架实施分散执行的实践范例。
