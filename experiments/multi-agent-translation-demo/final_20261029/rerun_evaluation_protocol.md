# 改造前后质量对照：本轮固定口径

本文件在改进版收费调用开始前固定。比较基线为 `run-20261026T153700605628Z`；新运行保持同一模型、同一PDF和同一章四块原文。流程及提示词变化，不能据一次运行证明因果或长期稳定性。

## 最终译文的两个主指标

准确性与中文表达分别报告。借鉴 MQM 对 Accuracy、Terminology 和语言表达错误的区分，但下列抽样检查点与1～5分量表为本实验自定义，不能称作标准MQM认证评分。参考：https://www.themqm.org/mqm-pillars/the-mqm-core-typology/ 。

1. **固定检查点准确率**：32个原文语义/完整性检查点，每块8项。1=语义要素正确完整；0=明确错译、漏译或增译；U=依据不足待核定。主数值为正确数/32，并单列失败数、待核定数；U不计作正确。检查点含关键关系、主体、条件、否定、数字、脚注。它是定向诊断样本的准确率，不是整章或全部句子的准确率。旧/新初稿和旧/新修订稿采用同一清单。
2. **中文表达质量**：每块分别评语法、搭配、连贯、用语四维，均为1～5分。5=未发现影响阅读的问题；4=少量局部生硬；3=多处需润色但大体可读；2=明显病句/断裂影响阅读；1=大面积难以理解。四维均值只表示本轮助手辅助语言评审，每项给例证，不冒充客观统计。普通英文残留归用语或表达缺陷；合法缩写、人名和参考文献英文不因含拉丁字母而扣分。

错译不能靠流畅度抵消；不把两项合成为一个分数。另列重大含义错误、脚注遗漏和未解决项。

## 各 Agent 的过程指标

- Glossary：全部输出并排；对误收片段、概念重复、关键缩写漏收逐项复查。对预先固定的关键概念清单统计覆盖，不把候选数或总收录量叫作准确率。争议译法单列。
- Translation：用上述32项和语言量表比较初稿与最终候选；保持相同原文和判据。
- Proofreading：以本轮明确标注的问题清单计算命中与漏报；逐条区分确认缺陷、合理风格建议、误报、待确认。引用格式通过不代表问题判断正确。若新报告未生成，指标记未完成，不填0分。
- Manager：按可执行动作统计返修目标落实、术语返修落实、终审是否执行；不得把与报告一致当成语义准确率。
- Revision：逐项跟踪修复、未修复和新问题；若未进入该阶段，明确无新修订输出。

## 评审边界与交付

本轮结果由助手对原文和保存输出进行辅助评审，保留原句及判断依据，供用户复核。真实模型运行失败也必须保留和展示，不自动重跑收费调用，不补造后续 Agent 输出。评估完成前不更新最终打卡结论、不提交或推送Git。
