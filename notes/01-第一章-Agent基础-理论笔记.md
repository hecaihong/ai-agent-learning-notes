## 本章解决什么问题

解释 Agent 为什么不只是一个聊天模型，以及模型、上下文、工具和 Harness 如何组成一个能持续行动的系统。

## 我的问题与困惑

### Agent 和普通大模型有什么区别？

**核心结论：**模型只生成决策；Agent 还包含上下文、工具和运行循环，能够根据工具结果继续行动。

### Model 和 Harness 分别负责什么？

- Model：理解任务、选择下一步、生成工具参数或最终回答。
- Harness：组织上下文、披露并执行工具、保存轨迹、校验权限、控制循环和停止条件。

### Harness 和 Computer Use 是什么关系？

Computer Use 是一种具体工具能力，例如截图、点击和输入。Harness 是管理整个模型运行和工具执行的外层系统。

### 预训练和后训练需要我自己做吗？

本课程前几章使用已经训练好的模型，不需要修改模型参数。预训练形成通用语言与知识能力；后训练进一步塑造指令遵循、工具使用和行为偏好。

### 上下文包含什么？

系统规则、用户消息、模型历史、工具定义、工具结果，以及当前任务需要的检索资料和状态。

### 谁决定调用工具，谁执行工具？

模型根据任务和工具说明决定调用什么、填写什么参数；Harness 校验后执行真实函数，再把结果返回模型。

## 怎么在实践中落地

```text
构造上下文
→ 模型生成下一步行动
→ Harness 校验并执行工具
→ 工具结果进入下一轮上下文
→ 模型继续行动或结束
```

判断 Agent 是否真的工作，不能只看最终答案，还要查看工具调用、参数、执行结果和停止原因。
