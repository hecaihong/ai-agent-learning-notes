# 我的 19 天 AI Agent 共学总结

整理日期：2026-10-29。精简稿，待改进版真实复测后定稿。

这 19 天，我从“Agent 就是给模型一个提示词”，逐渐理解了模型、上下文、工具和运行程序的分工。模型提出回答或工具调用，程序负责实际执行、记录状态并把结果送回模型。第一章的对照实验让我看到：不保留历史时，Agent 会重复已经做过的动作；看不到工具结果时，它也无法据此完成计算。

后续学习让我更关注材料是否可靠。上下文压缩减少了主 Agent 的输入，却没有让那次任务在规定轮数内完成。BM25 能找到词面一致的材料，也会漏掉同义表达。因此，文本更短、检索有结果，都需要结合最终任务效果来判断。工具与 MCP 的学习，则帮助我区分了模型可见的能力说明、真实函数和连接协议。

印象最深的是第十章。我选定一份真实英文材料，把教材样例改成术语、翻译、审校和调度四类角色协作的翻译实验，助手协助改造脚本与分析结果。过程中先遇到术语数量限制，再遇到输出截断，后来通过明确收录与排除的数据协议，完成了 11 次模型调用。

但逐个检查输出后，问题仍然明显：术语有误收和漏收；审校缺少英文原文；Manager 提出的补术语要求没有执行；修订改好了一个错字，又引入了未译英文，脚注也仍有遗漏。这次改造因此还不能算质量合格。我也认识到，记录调用次数、文件数量和 token，只能说明执行情况，无法直接证明内容正确。

目前已根据这些问题补上双语审校、旧稿精确修订、术语返修和最终检查，并完成离线回归测试。真实质量是否改善，还要用同一材料重跑，对比术语去留、漏译误译、问题修复和新增错误。这次共学让我开始沿着输入、执行、输出和验收去理解 Agent，也学会追问：一个结果到底凭什么值得相信。
