## 学习心得

本次学习了上下文工程、API 消息角色和工具调用流程，理解了模型根据任务与工具说明选择动作，Harness 执行 Python 函数并把结果送回上下文。我完成了自定义营收汇总工具的本地注册与校验，并运行第二章无压缩和按任务摘要两组对照。两组均在 5 轮上限内没有产出最终答案；摘要组主 Agent token 更少，但耗时更长，而且统计未包含摘要生成的额外用量。因此，判断压缩效果不能只看长度，还要核对关键信息、任务完成度和完整成本。我还学习了 KV Cache 与稳定前缀的关系，查看了作者历史报告，尚未用自己的 API 完成缓存对照。笔记中保留了原始结果及未完成事项。
