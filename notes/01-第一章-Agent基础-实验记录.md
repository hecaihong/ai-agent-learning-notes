## 实验一：Web Search Agent 与 DeepSeek 适配

### 要验证什么

观察一次搜索任务怎样形成“思考 → 行动 → 观察 → 再决策”的循环，并确认轨迹标签来自 Agent/Harness 的展示逻辑。

### 我的操作

1. 运行官方离线搜索演示。
2. 配置 DeepSeek API。
3. 编写搜索适配器，把搜索结果返回 Agent。
4. 搜索次数上限不足时出现 `max_uses_exceeded`，提高上限后完成搜索。

### 实际结果与分析

- DeepSeek 可以参与工具决策，但联网搜索能力来自外部搜索工具，不是模型 API 自动提供。
- “思考、行动、观察”等标签由 Agent/Harness 整理，不能当成模型 API 的固定字段。
- 搜索次数与问题复杂度、模型策略和停止条件有关，不应简单按模型品牌设置。

## 实验二：实验 1-1 上下文消融

### 要验证什么

保持模型和任务不变，只改变 Harness 提供的上下文，观察任务是否还能推进。

### 我的操作

使用 DeepSeek Flash 运行五种配置，最多 5 轮。任务是将四个季度营收换算成美元，再计算全年总额和季度平均值。

![20261014-官方五种实验配置](<../assets/实验截图/实验1-1/20261014-官方五种实验配置.png>)

### 实际结果

| 配置 | 模型轮数 | 工具调用 | 任务结果 |
|---|---:|---:|---|
| `full` | 3 | 4 | 成功 |
| `no_history` | 5 | 15 | 重复换汇，未完成 |
| `no_reasoning` | 4 | 5 | 成功 |
| `no_tool_calls` | 1 | 0 | 只有调用样式的文字，工具未执行 |
| `no_tool_results` | 5 | 10 | 看不到结果，拒绝给出金额 |

完整组得到全年总额 **9,602,895.73 美元**，季度平均 **2,400,723.93 美元**。

![20261014-对照实验启动与换汇](<../assets/实验截图/实验1-1/20261014-对照实验启动与换汇.png>)

### 结果分析

- 工具执行成功，不等于模型知道工具结果；结果必须进入下一轮上下文。
- 没有历史时，模型会重复已经完成的动作。
- 模型输出一段“像工具调用”的文字，不等于 Harness 实际执行了工具。
- 本题移除历史推理仍然成功，说明工具结果比历史推理更关键；这只是本次任务的结果，不能推广到所有任务。

### 实验结论

Agent 的表现由模型和 Harness 共同决定。上下文是否保留任务进度、工具定义和工具结果，会直接影响任务能否完成。
